# App icon

`AppIcon.png` is the raster source, generated with the built-in image generation tool. `build-icon.sh` uses macOS `sips` and `iconutil` to produce all Dock icon sizes and the `.icns` bundle. The generated artwork is provided under the project's MIT license to the extent applicable; it contains no vendor logo.

Generation prompt:

> Use case: stylized-concept. Create a polished raster macOS application icon for Burst Control, a precise gaming mouse configuration utility. Square 1024x1024 composition. A single sculptural wireless computer mouse viewed from above, slightly angled, with satin graphite shell, crisp split buttons and a tactile milled silver scroll wheel; one restrained warm orange accent in the wheel recess. Resting on an ivory porcelain rounded-square app tile, subtle bevel, soft dimensional studio shadows, careful industrial product design. Bold recognizable silhouette at small Dock sizes, beautifully rendered materials, spare and confident. The tile occupies about 88 percent of the canvas with transparent space around it. No text, no letters, no logos, no wires, no neon, no extra symbols, no background scene. This must be a finished icon asset, not a presentation mockup.
